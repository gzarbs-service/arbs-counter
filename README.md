# Учёт вилок GZ

Веб-приложение для учёта букмекерских вилок (arbitrage/surebets) с командной работой.

## Возможности

- Добавление вилок с произвольным количеством плеч.
- Ручной ввод ставки на каждое плечо.
- Автоматический расчёт общего банка и ожидаемой прибыли.
- Переключение валюты (EUR / USD).
- Роли пользователей: администратор и работник.
- Панель администратора для управления ролями.

## Стек

- Next.js 16 + React 19
- Tailwind CSS
- Supabase (Auth + PostgreSQL)
- Vercel

## Локальный запуск

Создай `.env.local` на основе `env.example` и запусти:

```bash
npm run dev
```

## Деплой

При пуше в ветку `main` GitHub Vercel автоматически запускает новый деплой.
